# Lume — A Ilha das Brasas

Uma pequena aventura 2D original, em português, feita com Canvas e JavaScript. Explore o bosque, fale com Íria, enfrente criaturas e acenda três faróis para despertar o templo.

## Jogar

Abra `index.html` em um navegador moderno. Não precisa instalar dependências nem fornecer arquivos de outros jogos.

- WASD ou setas: mover
- Espaço: espada
- E: conversar e interagir
- P / Esc: pausar
- No celular: botões de toque

O progresso dura enquanto a página está aberta. Recarregar ou recomeçar reinicia a aventura. O som é opcional.

## GitHub Pages

O workflow em `.github/workflows/pages.yml` publica os arquivos estáticos a cada push para `main`. Em Settings → Pages, selecione GitHub Actions como fonte se o Pages ainda não estiver habilitado.

## Créditos

Personagens, mapa, história e desenhos em pixels são originais, criados para este protótipo. Não utiliza arquivos de Zelda ou Nintendo.
